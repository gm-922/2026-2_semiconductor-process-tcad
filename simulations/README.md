# 공통 주제 시뮬레이션 기록

이 폴더는 **팀 전체가 수행하는 하나의 프로젝트 주제** 아래 진행되는 개별 TCAD 시뮬레이션을 기록합니다.

## 기본 원칙

- 팀 전체가 **공통 주제**를 공유하며, `SIM-001`, `SIM-002` 등의 ID는 그 안의 실험·조건 비교를 구별합니다.
- 시뮬레이션 기록은 팀원별로 나누지 않고 **공동 자료**로 관리합니다.
- 각 시뮬레이션의 주제/세부 목적, 공정 조건 및 변수, 사용 명령어, 결과와 해석을 분리해 기록합니다.
- 시뮬레이션을 실제로 준비하거나 수행할 때 해당 폴더를 생성합니다.

## 예정 구조(예시)

```text
simulations/
├── README.md
├── SIM-001/
│   ├── README.md       # 개별 시뮬레이션 목적/조건/결과 요약
│   ├── sprocess.cmd    # 실제 사용한 Sentaurus Process 명령어
│   └── results/        # 필요한 결과 그래프 및 분석 자료
└── SIM-002/
    └── ...
```

- 아직 공통 프로젝트 주제와 개별 시뮬레이션은 **미정**입니다.
- 공통 주제가 정해진 뒤 시뮬레이션을 번호 순서로 등록합니다.
- 양식: [시뮬레이션 기록 템플릿](../templates/simulation_template.md)
- 용량이 큰 TCAD 생성 파일은 원격 실행 환경에 두고, GitHub에는 필요한 코드와 요약 결과 위주로 보관합니다.
