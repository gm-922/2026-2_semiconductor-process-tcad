# 반도체공정의 이해 — 2026학년도 2학기 기말프로젝트

Sentaurus TCAD를 활용하여 평판 실리콘 기판의 공정 조건에 따른 깊이별 도핑 농도 분포를 비교·분석하는 4인 팀 프로젝트입니다.

## 1. 프로젝트 개요

- **과목/학기:** 반도체공정의 이해 / 2026학년도 2학기
- **시뮬레이션 도구:** Sentaurus TCAD (Sentaurus Workbench / Sentaurus Process)
- **현재 연구 주제 [2026-11-18 변경 확정]:** **「다중 에너지 이온주입을 통한 Box-like 도핑 프로파일 형성 및 RTA 공정에 따른 특성 분석」**
- **연구 대상:** 평판 Si 기판에서 깊이 방향의 이온주입 도핑 농도 분포
- **주요 목표:** 단일 에너지별 분포를 분석한 뒤, 다중 에너지 주입으로 관심 깊이 구간에 가능한 한 평탄한 Box-like Profile을 형성하고 **이온주입 횟수** 및 **RTA 수행 방식**에 따른 차이를 비교·해석
- **진행 단계:** 새 주제 확정, 세부 파라미터 및 시뮬레이션 조건 조사·선정 전 단계. 실행 결과는 아직 확인되지 않음.

### 실무적 배경과 연구 범위

CMOS의 Retrograde Well(P-Well/N-Well) 형성은 다중 에너지 주입을 연구하는 **실무적 필요성·동기**를 설명하는 사례입니다. Retrograde Well 구조 자체의 재현이나 CMOS/MOSFET의 전기적 특성 해석은 이번 연구의 직접 목표가 아닙니다. **Retrograde Profile과 Box-like Profile은 다른 개념**으로 구분합니다.

- 허용 공정: 산화, 확산, 이온주입. 현재 선택한 중심 공정은 이온주입 및 RTA 열처리.
- 평판이 아닌 MOS 구조의 구현·분석을 주제로 삼지 않음.
- 분석 중심: 깊이별 도펀트 농도 분포, 목표 구간에서의 평탄도, RTA 전후 프로파일 변화 및 물리적 이유.

## 2. 현재 연구 구성

### 연구 1 — 단일 에너지 이온주입 특성 분석

다양한 주입 에너지에서 단일 이온주입을 각각 수행해 에너지별 깊이-농도 분포를 비교합니다. Projected Range(`R_p`), Range Straggling(`ΔR_p`), Dose, 주입 분포 모델(Pearson 계열 등)을 검토하고, **연구 2의 에너지 조합 및 Dose 선정 근거**를 마련합니다. 실제 적용 모델은 TCAD 설정에 따라 확인합니다.

### 연구 2 — 다중 에너지 이온주입 횟수 및 RTA 방식의 영향

서로 다른 에너지를 조합한 다중 이온주입을 통해 관심 깊이 구간의 Box-like Profile을 구현하려고 시도합니다. 비교 변수는 **(1) 이온주입 횟수**와 **(2) RTA 수행 방식**입니다.

- **Case A (매회 RTA):** Implant 1 → RTA → Implant 2 → RTA → … → Implant N → RTA
- **Case B (최종 RTA 1회):** Implant 1 → Implant 2 → … → Implant N → RTA
- 예를 들어 2·3·4회 주입 조합을 비교할 수 있지만, **구체적 비교 횟수는 아직 미정**입니다.
- 두 Case를 각 주입 횟수에서 수행하여 최종 깊이별 농도 분포, 목표 구간의 평탄도 및 RTA 수행 방식의 영향을 비교합니다.
- 주입 횟수가 늘어난다고 반드시 평탄도가 향상되는 것은 아니며, 실제 TCAD 결과로 판단합니다.
- 주입 횟수에 따른 비교에서 총 Dose, 목표 깊이 구간 등 비교 기준을 관리합니다. Case A/B의 누적 열처리 시간이 서로 달라질 수 있다는 점을 결과 해석에 명시합니다.
- 초기 필수 비교는 **Case A와 B 두 가지**로 제한합니다. 추가 실험안은 별도 결정 전까지 포함하지 않습니다.

## 3. 미확정 파라미터와 분석 지표

문헌, 강의자료 및 합리적인 공정 범위를 조사한 후 시뮬레이션 조건을 결정합니다.

- **미정:** 이온종(B, P 등), 기판 조건/결정방위/초기 도핑, 관심 깊이 구간, 목표 농도 및 허용 편차, 주입 에너지·횟수·각 Dose·총 Dose, 입사각, 주입 분포 및 손상 모델, RTA 온도·시간·승온/냉각 조건, 확산/활성화 모델 등.
- **가능한 분석 항목(채택 전):** 깊이별 도핑 농도 곡선, 관심 구간의 평균 농도와 농도 편차/최대·최소 차이, 표면 농도, RTA 전후 변화.
- 예시 에너지(150→80→50 keV), 2·3·4회 주입, 특정 깊이 구간 등 기존 대화에 등장한 숫자는 **실험 확정값이 아닙니다**.
- 물리적 해석에서 주입 분포의 중첩, Channeling, 이온주입 손상, 열처리에 의한 확산·결함 회복·도펀트 활성화 등을 실제 적용 모델 및 결과와 연계하여 검토합니다.

## 4. 연구 수행 원칙

1. 강의자료를 우선 학습하고, 필요한 논문과 Sentaurus 공식 문서를 추가로 조사합니다. 출처를 구분합니다.
2. 연구 목적·변수 설정 → 이론 및 수식 학습 → 예상 경향 정리 → 조건 확정 → TCAD 실행 → 결과 추출 → 이론과 비교·원인 분석 → 결론 순으로 진행합니다.
3. 이론적 예상, 문헌 사실, 실제 실행 결과를 명확히 구분합니다. 실행하지 않은 코드·수치·결과를 완료로 기록하지 않습니다.
4. 연구 세부 조건은 진행 중 변경할 수 있으나 변경 이력을 남깁니다. 단일한 '최적 횟수'를 미리 가정하지 않습니다.
5. 연구 대상은 평판 Si이며 소자 전기적 성능의 정량 검증을 주장하지 않습니다.
