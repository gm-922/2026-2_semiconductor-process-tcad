# SIM-000 / 2차 — 20·170 keV 단일 B 주입의 Grid 수렴성 비교

- **수행일:** 2026-11-23
- **상태:** 6개 조건 `done`(사용자 확인); PLX XY CSV 업로드·정량 분석 완료.
- **목적:** 1차(80 keV)에서 잠정 선정한 2 nm가 얕은 주입(20 keV)과 깊은 주입(170 keV)에서도 안정적으로 BTotal 분포를 재현하는지 검증하고, **SIM-000의 as-implanted 기준 Grid를 선정**한다.
- **근거 자료:** [원본 XY CSV](results/2nd_grid_convergence.csv), [계산 지표 CSV](results/convergence_metrics.csv). **2차 원본 `.cmd`, TDR 바이너리 및 서버 로그 파일은 GitHub에 별도로 업로드하지 않았다.**
- **전체 종합 결론:** [상위 SIM-000 README](../README.md).

## 1. 실제 비교 설계

| 공통 조건 | 적용 값 |
|---|---|
| 도구 | Sentaurus Workbench / Sentaurus Process / Sentaurus Visual (학교에서 사용한 T-2022.03) |
| 기판 | 평판 1D Silicon, (100), 초기 n형 P 1×10¹⁵ cm⁻³ |
| Boron Dose | 1×10¹² cm⁻² (모든 비교에서 동일) |
| Tilt / Rotation | 7° / 22° |
| 에너지 변수 | **20, 170 keV** |
| Grid 변수 | **0.5, 2, 5 nm** (0~0.8 µm 설정 구간) |
| RTA | 미실시 (as-implanted) |
| 관심 구간 | 0.05~0.45 µm |
| 추가 분포 비교 | **0~0.8 µm**, 170 keV의 피크 0.518 µm 포함 |
| 기준 | 같은 에너지의 0.5 nm 결과를 잠정 Reference로 사용 |

| SWB node | Energy | Grid |
|---|---:|---:|
| n2 | 20 keV | 0.5 nm |
| n8 | 20 keV | 2 nm |
| n9 | 20 keV | 5 nm |
| n12 | 170 keV | 0.5 nm |
| n13 | 170 keV | 2 nm |
| n14 | 170 keV | 5 nm |

1차 1 nm 조건은 이번 2차 스윕에서는 제외했다. 기존 1차(80 keV)의 1 nm 자료는 [1차 기록](../run-01_80keV/README.md)에 보존되어 있다.

## 2. 실행 과정 및 오류·수정 이력

1. 기존 1차 프로젝트를 보존하고 별도 Workbench 프로젝트 **`grid_nm2`**에서 2차 파라미터 스윕을 구성했다.
2. 1차 덱의 고정 `energy=80<keV>`를 SWB 매개변수 **`energy_keV`**로 바꿨다. `grid_nm` 값은 0.5/2/5 nm로 설정했다.
3. 최초 실행 시 여섯 노드가 모두 `failed`로 표시됐다. 로그에서 **`energy=20    <keV>`**처럼 에너지 숫자와 단위 사이 공백이 있는 문법 오류가 확인됐다. 해당 공백을 제거해 **`energy=@energy_keV@<keV>`** 형태로 수정하고 재전처리·재실행했다.
4. 사용자 확인 결과 **6개 모두 `done`**. S-Visual에서 여섯 `.plx`의 `BTotal` 대 깊이를 CSV로 추출해 이 문서의 분석에 사용했다.

**재현성 참고:** 상기 파라미터 및 오류 수정은 대화와 실행 화면을 바탕으로 기록했다. 실제 실행을 마친 **2차 원본 `sprocess_fps.cmd` 파일 자체는 제공되지 않았으므로** 이 문서에서 이를 검증된 코드 파일인 것처럼 첨부하지 않는다.

## 3. 실제 결과: 기준 Grid(0.5 nm) 대비

### A. 피크 특성

| Energy | Grid | Peak BTotal (cm⁻³) | 샘플 피크 깊이 (µm) | 피크 농도 오차 | 깊이 차이 |
|---:|---:|---:|---:|---:|---:|
| 20 keV | **0.5 nm** | 7.459735×10¹⁶ | 0.0840 | 기준 | 기준 |
| 20 keV | **2 nm** | 7.459735×10¹⁶ | 0.0840 | **0.000000%** | **0 nm** |
| 20 keV | **5 nm** | 7.458404×10¹⁶ | 0.0850 | 0.017842% | +1.0 nm |
| 170 keV | **0.5 nm** | 3.179637×10¹⁶ | 0.5180 | 기준 | 기준 |
| 170 keV | **2 nm** | 3.179637×10¹⁶ | 0.5180 | **0.000000%** | **0 nm** |
| 170 keV | **5 nm** | 3.178591×10¹⁶ | 0.5200 | 0.032897% | +2.0 nm |

샘플 피크 깊이의 차이는 **출력 좌표의 샘플링 차이**를 포함한다. 0.5 nm가 이론적 정확해임을 뜻하지 않는다.

### B. 농도 프로파일 비교 — 0~0.8 µm

| Energy | 비교 Grid | 정규화 RMSE | 최대 농도차/기준 피크 | 0.05~0.45 µm 평균 농도차 |
|---:|---:|---:|---:|---:|
| 20 keV | 2 nm | **0.004781%** | **0.026750%** | −0.004075% |
| 20 keV | 5 nm | 0.029912% | 0.166172% | −0.026905% |
| 170 keV | 2 nm | **0.001779%** | **0.006966%** | +0.002533% |
| 170 keV | 5 nm | 0.011132% | 0.043464% | +0.016731% |

- **계산법:** `x=0, 0.0005, ..., 0.8000 µm`의 동일 좌표에 각 Grid의 출력 곡선을 **선형 보간**한다. `NRMSE(%) = sqrt(mean((C_grid−C_ref)^2)) / max(C_ref) × 100`. 최대 차이도 `max(C_ref)`로 나눠 정규화한다.
- **20 keV:** 얕은 피크(0.084 µm) 주위에서 5 nm의 차이가 2 nm보다 크지만, 두 조건의 **피크 농도 오차는 각각 0% (CSV 자릿수 내), 0.01784%**이다.
- **170 keV:** 피크가 **0.518 µm**로 팀의 0.05~0.45 µm 관심 구간 밖이다. 따라서 분포 전체에 가까운 **0~0.8 µm** 비교를 함께 적용했다.
- **보조 확인:** 출력 전체 0~2 µm 적분 B Dose의 0.5 nm 대비 오차는 20 keV에서 **2 nm −0.001213%, 5 nm −0.007994%**, 170 keV에서 **2 nm +0.000268%, 5 nm +0.000315%**이다. 입력 Dose 자체는 모든 조건에서 동일했다.

### C. 1차(80 keV)와의 비교

| Energy | 2 nm 피크 위치 차이 | 5 nm 피크 위치 차이 | 2 nm NRMSE(0~0.8 µm) | 5 nm NRMSE(0~0.8 µm) |
|---:|---:|---:|---:|---:|
| 20 keV | 0 nm | +1.0 nm | 0.004781% | 0.029912% |
| **80 keV (1차)** | **+0.5 nm** | **+2.5 nm** | 0.001886% | 0.011807% |
| 170 keV | 0 nm | +2.0 nm | 0.001779% | 0.011132% |

1차 기록의 0.05~0.45 µm RMSE와 표의 0~0.8 µm RMSE를 **서로 다른 평가 구간이라는 설명 없이 직접 동일시하지 않는다**.

## 4. 2차 결과 해석과 최종 결정

**관찰:** 20/170 keV 모두 2 nm와 5 nm의 출력 농도 프로파일 차이는 작고, 2 nm의 정규화 RMSE가 더 작았다. 2 nm는 세 에너지(1차 80 keV 포함)에서 피크 깊이 차이가 **최대 0.5 nm**였고, 5 nm는 80·170 keV에서 각각 **2.5·2.0 nm** 차이를 보였다.

**판단:** 프로젝트의 잠정 기준(피크 농도 ≤1%, 표본 피크 위치 차이 ≤1 nm, 정규화 RMSE ≤2% 등)을 일관되게 만족하고 0.5 nm보다 적은 출력 데이터를 요구하는 **2 nm를 후속 as-implanted 단일·다중 이온주입의 기준 Grid로 결정**한다.

**한계:** 5 nm의 비교 오차가 크지 않다는 사실을 그대로 기록하며, 표본 피크 위치 차이를 물리적 피크 이동으로 단정하지 않는다. 실제 CPU 시간·메모리·원본 TDR 내부 Mesh 토폴로지는 미검증이다. 또한 **RTA 확산·활성화**, 다른 주입 모델, 후속 확정 에너지·Dose 조건에서의 Grid 수렴성은 **별도 검증이 필요**하다.
