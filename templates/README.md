# 기록 양식 (templates/)

새 활동 및 실제 TCAD 실행 결과를 **일관된 형식으로 기록할 때** 사용하는 빈 양식입니다. 양식은 복사해서 아래의 실제 기록용 폴더에 저장합니다.

| 양식 | 용도 | 실제 기록 위치 |
|---|---|---|
| [activity_template.md](activity_template.md) | 팀원별 날짜·활동 내역 | [activities/](../activities/README.md) |
| [simulation_template.md](simulation_template.md) | 실험 목적·조건·명령어·로그·결과·해석 | [simulations/](../simulations/README.md) |

사전 조사와 **실행되지 않은** TCAD 입력 코드 초안은 별도 [box-profile-tcad/](../box-profile-tcad/README.md)에 보관합니다.
