# 반도체공정의 이해 — 2026학년도 2학기 기말프로젝트

Sentaurus TCAD를 활용하여 반도체 공정 조건의 변화가 시뮬레이션 결과에 미치는 영향을 분석하는 기말프로젝트입니다.

## 1. 프로젝트 개요

- **과목:** 반도체공정의 이해
- **학기:** 2026학년도 2학기
- **활용 도구:** Sentaurus TCAD (Sentaurus Workbench / Sentaurus Process)
- **현재 상태:** 주제 선정 전

산화·확산·이온주입 공정 중 주제를 정하고, 관련 공정 변수를 변화시키며 시뮬레이션을 수행합니다. 얻어진 결과를 학습한 이론과 연결해 해석하는 것이 프로젝트의 핵심입니다.

## 2. 주제 선정 범위와 제한 사항

- **허용 범위:** 산화(Oxidation), 확산(Diffusion), 이온주입(Ion Implantation)
- **제한 사항:** 평판이 아닌 MOS 구조에 관한 주제는 선정하지 않습니다.
- **연구 방향:** 선택한 공정에 대해 여러 변수의 변화에 따른 시뮬레이션 결과를 관찰·비교·분석합니다.
- **주제 상태:** 구체적인 주제와 변수, 시뮬레이션 조건은 아직 정해지지 않았습니다.

## 3. 주제 선정 시 명확히 할 사항

주제를 확정할 때 아래 내용이 드러나도록 구성합니다.

1. **학습 내용과의 연계:** 수업에서 학습한 어떤 내용을 배경으로 하는지
2. **이론적 배경:** 분석 대상 공정과 변수의 작동 원리 및 관련 이론
3. **주제 선정 이유:** 해당 현상이나 공정 조건을 탐구하려는 목적
4. **시뮬레이션 및 결과 분석:** 변수 변화에 따른 결과의 비교와 해석
5. **결론 및 향후 방향:** 분석을 통해 도출한 결론과 후속 탐구 가능성

## 4. 기본 진행 흐름

주제 선정 → 관련 이론 정리 → 시뮬레이션 변수·조건 설정 → TCAD 시뮬레이션 → 결과 분석 → 결론 및 향후 방향 정리

## 5. 작업 환경 및 저장소 운영 원칙

- **기본 작업 환경:** ChatGPT + GitHub를 이용한 자료·코드 검토 및 관리
- **시뮬레이션 실행 환경:** MobaXterm을 통한 SSH 접속 및 Sentaurus Workbench 활용(별도 요청 시 지원)
- **변경 원칙:** GitHub 파일의 생성·수정·삭제 및 커밋 등의 변경은 사용자의 명시적 요청 또는 사전 동의가 있을 때만 진행

> 이 문서는 프로젝트의 기본 개요와 조건을 기록한 문서입니다. 주제가 확정되면 구체적인 연구 계획을 별도로 정리합니다.


## 6. 팀 구성 및 기록 관리

- **팀 운영:** 4명이 **하나의 공통 프로젝트 주제**를 선정하고 함께 연구 및 시뮬레이션 진행
- **팀원:** 최강민(조장), 박경록, 서연희, 이동제
- **팀원별 활동:** 날짜별로 팀원의 수행 내용은 각각 기록 — [activities/](activities/README.md)
- **공통 시뮬레이션:** 팀원별로 별도 주제를 만들지 않고 공통 프로젝트의 시뮬레이션을 ID별로 관리 — [simulations/](simulations/README.md)
- **기록 양식:** [활동 기록](templates/activity_template.md) · [시뮬레이션 기록](templates/simulation_template.md)

> 실제 활동 날짜와 시뮬레이션 내용은 확인된 시점에만 추가합니다. 현재 공통 주제는 미정입니다.
