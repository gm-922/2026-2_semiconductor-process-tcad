# 반도체공정의 이해 — 2026학년도 2학기 기말프로젝트

Sentaurus TCAD를 활용하여 평판 실리콘 기판의 공정 조건에 따른 깊이별 도핑 농도 분포를 비교·분석하는 4인 팀 프로젝트입니다.

## 1. 프로젝트 개요

- **과목/학기:** 반도체공정의 이해 / 2026학년도 2학기
- **시뮬레이션 도구:** Sentaurus TCAD (Sentaurus Workbench / Sentaurus Process)
- **현재 연구 주제 [2026-11-18 변경 확정]:** **「다중 에너지 이온주입을 통한 Box-like 도핑 프로파일 형성 및 RTA 공정에 따른 특성 분석」**
- **연구 대상:** 평판 Si 기판에서 깊이 방향의 이온주입 도핑 농도 분포
- **주요 목표:** 단일 에너지별 분포를 분석한 뒤, 다중 에너지 주입으로 관심 깊이 구간에 가능한 한 평탄한 Box-like Profile을 형성하고 **이온주입 횟수(1~4회)** 및 **RTA 수행 방식**에 따른 차이를 비교·해석
- **진행 단계:** 새 주제 확정, 세부 파라미터 및 시뮬레이션 조건 조사·선정 전 단계. 실행 결과는 아직 확인되지 않음.

### 실무적 배경과 연구 범위

CMOS의 Retrograde Well(P-Well/N-Well) 형성은 다중 에너지 주입을 연구하는 **실무적 필요성·동기**를 설명하는 사례입니다. Retrograde Well 구조 자체의 재현이나 CMOS/MOSFET의 전기적 특성 해석은 이번 연구의 직접 목표가 아닙니다. **Retrograde Profile과 Box-like Profile은 다른 개념**으로 구분합니다.

- 허용 공정: 산화, 확산, 이온주입. 현재 선택한 중심 공정은 이온주입 및 RTA 열처리.
- 평판이 아닌 MOS 구조의 구현·분석을 주제로 삼지 않음.
- 분석 중심: 깊이별 도펀트 농도 분포, 목표 구간에서의 평탄도, RTA 전후 프로파일 변화 및 물리적 이유.

## 2. 확정된 시뮬레이션 진행 과정 (2026-11-18 세부 수정)

### 시뮬레이션 1 — 단일 에너지 이온주입 특성 분석

- 여러 에너지 레벨별 **단일 주입**을 수행하여 깊이별 도펀트 농도 프로파일을 비교합니다.
- Pearson 계열 등 이온주입 분포 모델의 적용 여부를 확인하고, 실제 프로파일 형태·피크 깊이·분포 폭·Projected Range·Range Straggling을 분석합니다. **Pearson 분포가 반드시 관찰된다고 단정하지 않습니다.**
- 에너지에 따른 분포 차이를 파악하기 위해 초기 비교에서는 동일한 Dose를 사용하는 방향을 우선 검토합니다.
- **목적:** 관심 깊이 구간의 Box-like Profile을 만들기 위한 유효 에너지 후보를 선정합니다.

### 시뮬레이션 2 — 주입 횟수(1~4회)별 Box-like Profile 형성

- 다중 에너지 주입 횟수를 **1·2·3·4회**로 바꾸며 프로파일을 비교합니다. **1회는 단일 주입 기준선**입니다.
- **횟수별 총 주입 Dose는 동일하게 유지**하고, 각 에너지에 배분하는 **개별 Dose의 비율은 달라질 수 있습니다.** 각 조건의 Dose 합이 동일하도록 설계합니다.
- 에너지 조합과 Dose 배분은 시뮬레이션 1과 후속 검토 결과에 따라 결정합니다. 예시 `150 → 80 → 50 keV`는 확정 조건이 아닙니다.
- 주요 비교: 관심 깊이 구간 내 농도 분포, 평균·편차 등 평탄도 지표, 목표 농도와의 차이.
- 횟수 증가의 이점은 실제 결과로 판단하며, 횟수별 에너지 조합·Dose 배분의 변화가 결과에 미치는 영향도 함께 명시합니다.
- **단계 2와 단계 3을 구분하기 위해**, 단계 2에서는 우선 추가 RTA 전의 주입 직후(as-implanted) 프로파일을 비교하는 방향으로 계획합니다(구체적 실험 설계 시 확인).

### 시뮬레이션 3 — RTA 수행 방식 비교

- 시뮬레이션 2에서 정한 각 주입 횟수별 **에너지·주입 순서·개별 Dose 값을 Case A/B에서 동일하게 유지**합니다. 동일한 기본 기판 및 주입 조건도 유지합니다.
- **Case A: 매회 RTA** — Implant 1 → RTA → Implant 2 → RTA → … → Implant N → RTA.
- **Case B: 최종 RTA 1회** — Implant 1 → Implant 2 → … → Implant N → RTA.
- **초기 비교는 A/B 두 Case만 진행**합니다. 1회 주입에서는 동일 RTA 조건을 적용하면 A/B 절차가 같아져 실질적인 RTA 방식 비교는 2~4회에서 발생합니다.
- RTA 횟수 차이에 따라 누적 열처리 시간이 달라질 수 있으므로 **수행 시점만의 영향으로 단정하지 않습니다**. 확산, 손상 회복, 활성화 및 모델에 따라 나타나는 주입 분포 변화 가능성을 검토합니다.
- 실제 공정에서 '항상 RTA 1회만 수행한다'는 전제는 사용하지 않습니다. 공정 통합 및 열처리 횟수를 정하는 이유는 문헌을 조사하고, A/B 결과를 바탕으로 장단점을 해석합니다.

### 최종 결과 방향

1. **시뮬레이션 2:** 동일 총 Dose 조건에서 1~4회 이온주입별 Box-like Profile 형성 여부와 평탄도를 비교하고 상대적으로 유리한 횟수·설계 조건을 검토.
2. **시뮬레이션 3:** 같은 횟수·에너지·개별 Dose에 대해 매회 RTA와 최종 RTA 1회의 결과를 비교하여 차이와 물리적 원인 설명.
3. **결론:** 단일 주입 특성 → 다중 주입 설계 → RTA 방식 비교로 이어지는 결과를 이론과 연결. TCAD에서 관찰되지 않은 효능이나 실제 공정의 보편적 사용 방식을 단정하지 않음.

## 3. 미확정 파라미터와 분석 지표

문헌, 강의자료 및 합리적인 공정 범위를 조사한 후 시뮬레이션 조건을 결정합니다.

- **미정:** 이온종(B, P 등), 기판 조건/결정방위/초기 도핑, 관심 깊이 구간, 목표 농도 및 허용 편차, 주입 에너지·각 Dose·총 Dose의 수치, 입사각, 주입 분포 및 손상 모델, RTA 온도·시간·승온/냉각 조건, 확산/활성화 모델 등.
- **가능한 분석 항목(채택 전):** 깊이별 도핑 농도 곡선, 관심 구간의 평균 농도와 농도 편차/최대·최소 차이, 표면 농도, RTA 전후 변화.
- 예시 에너지(150→80→50 keV)와 특정 깊이·농도 수치는 **실험 확정값이 아닙니다**. 주입 횟수는 **1~4회 비교로 확정**, 총 Dose의 수치와 에너지별 배분 비율은 미정입니다.
- 물리적 해석에서 주입 분포의 중첩, Channeling, 이온주입 손상, 열처리에 의한 확산·결함 회복·도펀트 활성화 등을 실제 적용 모델 및 결과와 연계하여 검토합니다.

## 4. 연구 수행 원칙

1. 강의자료를 우선 학습하고, 필요한 논문과 Sentaurus 공식 문서를 추가로 조사합니다. 출처를 구분합니다.
2. 연구 목적·변수 설정 → 이론 및 수식 학습 → 예상 경향 정리 → 조건 확정 → TCAD 실행 → 결과 추출 → 이론과 비교·원인 분석 → 결론 순으로 진행합니다.
3. 이론적 예상, 문헌 사실, 실제 실행 결과를 명확히 구분합니다. 실행하지 않은 코드·수치·결과를 완료로 기록하지 않습니다.
4. 연구 세부 조건은 진행 중 변경할 수 있으나 변경 이력을 남깁니다. 단일한 '최적 횟수'를 미리 가정하지 않습니다.
5. 연구 대상은 평판 Si이며 소자 전기적 성능의 정량 검증을 주장하지 않습니다.
