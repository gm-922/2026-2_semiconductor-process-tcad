# 팀원별 날짜 활동 기록

이 폴더는 **하나의 공통 기말프로젝트 주제**를 수행하는 4명의 활동을 날짜별·팀원별로 기록합니다.

## 팀 구성

| 이름 | 구분 |
| --- | --- |
| 최강민 | 조장 |
| 박경록 | 팀원 |
| 서연희 | 팀원 |
| 이동제 | 팀원 |

## 기록 구조

활동이 실제로 발생한 날에만 날짜 폴더를 만들고, 해당 날짜에 활동한 팀원의 파일을 작성합니다.

```text
activities/
├── README.md
└── YYYY-MM-DD/
    ├── 최강민.md
    ├── 박경록.md
    ├── 서연희.md
    └── 이동제.md
```

- 위 구조는 **예시**입니다. 활동 기록이 없는 날짜나 인원의 파일을 임의로 만들지 않습니다.
- 모든 활동은 **같은 팀 프로젝트 주제**를 위한 작업입니다. 팀원별로 별도 연구 주제를 정하는 구조가 아닙니다.
- 활동자, 날짜, 수행 내용, 결과, 후속 계획을 작성합니다.
- 시뮬레이션 관련 활동은 공통 시뮬레이션 ID(예: `SIM-001`)를 기재해 연결합니다.
- 기록 양식: [활동 기록 템플릿](../templates/activity_template.md)
- 실제 활동 내용과 파일 변경은 사용자의 요청 또는 사전 동의에 따라 반영합니다.
