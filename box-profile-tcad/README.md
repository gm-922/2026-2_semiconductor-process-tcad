## 팀 프로젝트에서 확정한 내용 vs. 이번 ZIP의 제안 조건

**팀 확정:** 평판 Si, 1·2·3·4회 주입 비교, **횟수별 총 Dose 동일**, 시뮬레이션 3은 동일 주입 조건의 **Case A(매회 RTA) vs B(마지막 한 번 RTA)** 비교. Retrograde well은 배경 사례일 뿐 직접 구현 대상이 아닙니다.

**이번 ZIP의 시작 조건(팀 확정 아님):**
- Boron 주입 / (100) Si / 초기 Phosphorus 1×10¹⁵ cm⁻³
- 목표 깊이 **0.05–0.45 µm**, 목표 농도 **1×10¹⁷ cm⁻³**, 총 Dose **4×10¹² cm⁻²**
- Tilt 7°, rotation 22° / 기본 RTA **1050°C, 10초**
- 1회 110 keV; 2회 35·115 keV; 3회 20·55·130 keV; 4회 20·50·100·170 keV. 자세한 Dose 배분은 [designs_lss.json](analysis/designs_lss.json).

에너지 조합 및 평탄도 지표는 **LSS 근사·탐색 범위 안에서 구한 초기 후보**입니다. 실행 전 공식 매뉴얼·강의자료와 TCAD 단일 주입 결과로 재검토해야 합니다.

## 파일 이름으로 실험 찾기

| 파일 접두어 | 내용 | 개수 |
|---|---|---:|
| `S0_` | 격자 간격 0.5/1/2/5 nm 수렴성 확인 | 4 |
| `S1_B_` | 단일 에너지별 Boron 주입 (20–170 keV 중 13개) | 13 |
| `S1b_` | 80 keV에서 Dose 비례성 검토 | 2 |
| `S2_` | 단일 프로파일 합과 연속 주입의 중첩 검증 | 1 |
| `S5_` | **주입 횟수 1–4회, as-implanted 비교** | 4 |
| `S6_` | **RTA A/B**, 추가 제안 C, 모델 차등 조건 | 18 |
| `S6b_` | 추가 제안 열처리 온도·시간 sweep | 4 |
| **합계** | [실행 목록 CSV](tcad/run_list.csv) 참조 | **46** |

> **범위 유의:** `S6_*_C_*`, `S6b_*`, 모델 on/off 비교는 **ZIP 작성자의 확장 제안**으로, 팀이 승인한 A/B 기본 실험 범위에 자동 포함되지 않습니다.

## 완료 여부 / 해석상 주의

| 항목 | 상태 |
|---|---|
| 참고문헌 기반 검토·설계 문서 | ZIP에 작성되어 있음(출처별 타당성 재검토 필요) |
| Python Gaussian/LSS 계산·예측 그래프 | ZIP에 산출물 포함 |
| TCAD `.cmd` 46개 | **입력 파일 작성됨**, 환경 호환성 미검증 |
| Sentaurus 실행 로그·`.plx`·`.tdr` | **원본 ZIP에 없음** |
| 실제 TCAD 프로파일·결과 분석 | **실행 확인 전, 미확보** |

`AdvancedCalibration`, `wafer.orient`, `pdbSet`, `SetPlxList`, `WritePlx` 등을 학교에서 쓰는 Sentaurus 버전과 대조해야 합니다. 코드의 `TEDon`/`TEDoff`는 **서로 다른 확산 모델명에 붙인 비교용 이름**이므로 그 결과 차이를 TED 효과만으로 해석하면 안 됩니다.
