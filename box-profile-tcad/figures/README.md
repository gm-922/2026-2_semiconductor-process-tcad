# 이론 예측 그래프: GitHub용 SVG 미리보기

사용자가 제공한 ZIP에는 Gaussian(LSS) 근사에 따른 PNG 그래프 3개가 포함되어 있습니다. 이 폴더에는 해당 모델·설계 수치를 이용해 GitHub에서 바로 볼 수 있도록 **SVG로 새로 그린 웹 미리보기**를 보관합니다. **원본 PNG와 동일한 이미지 바이너리는 아닙니다.**

| 그림 | 내용 |
|---|---|
| [fig0_single_profiles.svg](fig0_single_profiles.svg) | 단일 에너지별 깊이 방향 농도 |
| [fig1_designs.svg](fig1_designs.svg) | 동일 총 Dose에서 1·2·3·4회 Box-like 프로파일 비교 |
| [fig2_anneal_sequences.svg](fig2_anneal_sequences.svg) | 3회 주입의 A/B/C 열확산 및 간이 TED 가정 차이 |

**주의:** 이론적 예상이지 Sentaurus TCAD 실제 출력이 아닙니다. 원래 PNG는 제공받은 ZIP이나 `analysis/make_figures.py`를 실행해 확인하세요. C 및 TED 가정은 팀이 확정한 기본 연구 범위를 넘어서는 보조 제안입니다.
