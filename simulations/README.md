# 공통 주제 시뮬레이션 기록

이 폴더는 **팀 전체가 수행하는 하나의 프로젝트 주제** 아래 진행되는 개별 TCAD 시뮬레이션을 기록합니다.

## 기본 원칙

- 팀 전체가 **공통 주제**를 공유하며, `SIM-001`, `SIM-002` 등의 ID는 그 안의 실험·조건 비교를 구별합니다.
- 시뮬레이션 기록은 팀원별로 나누지 않고 **공동 자료**로 관리합니다.
- 각 시뮬레이션의 주제/세부 목적, 공정 조건 및 변수, 사용 명령어, 결과와 해석을 분리해 기록합니다.
- 시뮬레이션을 실제로 준비하거나 수행할 때 해당 폴더를 생성합니다.


## 실제 수행 기록

| 실험 ID | 내용 | 상태 | 기록 |
| --- | --- | --- | --- |
| **SIM-000** | Sentaurus Process 단일 B 주입(80 keV)의 Grid 수렴성 1차 검토 | **1차 실행·정량 비교 완료 (2026-11-23); 후속 Grid 검증 미완료** | [sim-000/README.md](sim-000/README.md) · [1차 결과](sim-000/run-01_80keV.md) |

## 예정 구조(예시)

```text
simulations/
├── README.md
├── SIM-001/
│   ├── README.md       # 개별 시뮬레이션 목적/조건/결과 요약
│   ├── sprocess.cmd    # 실제 사용한 Sentaurus Process 명령어
│   └── results/        # 필요한 결과 그래프 및 분석 자료
└── SIM-002/
    └── ...
```

- **확정 공통 주제:** 다중 에너지 이온주입을 통한 Box-like 도핑 프로파일 형성 및 RTA 공정에 따른 특성 분석.
- **확정된 시뮬레이션 계획:** (1) 여러 에너지의 단일 주입 분포 확인 및 유효 에너지 검토, (2) **동일 총 Dose** 하에서 **1~4회 주입**의 Box-like Profile 비교(에너지별 Dose 비율 조절 가능), (3) 횟수별 **동일 에너지·동일 개별 Dose**를 사용하여 **매회 RTA(Case A)**와 **최종 RTA 1회(Case B)** 비교.
- **예정 출력:** 깊이별 농도 분포, 관심 구간의 농도 평탄도, 횟수별 비교, RTA 방식별 변화와 물리적 해석.
- **후속 본 연구 조건은 미확정:** 에너지 조합·총 Dose 수치, 이온종, 목표 깊이·농도, RTA 온도·시간 및 모델. 단, **SIM-000 1차 Grid 검증**은 2026-11-23 실제 실행했으며 그 실험에 사용한 80 keV·1×10¹² cm⁻²·B 조건과 결과는 해당 폴더에 기록했습니다.
- 번호와 파일을 실제 수행한 경우에만 등록합니다. 예정된 본 연구 단계의 계획은 실행 완료를 뜻하지 않습니다.
