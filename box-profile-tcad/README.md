# Box-like 도핑 프로파일 — TCAD 실행 전 사전자료·입력 코드

> **자료 상태 (2026-11-23 등록):** 업로드된 `팀공유_box_profile_TCAD.zip`의 연구·코드 자료를 정리하는 보관 영역입니다. 이 폴더의 수치와 그래프는 **Gaussian(LSS) 모델 기반 사전 예측 및 제안 조건**이며, **Sentaurus TCAD 실측/실행 완료 결과가 아닙니다.**

## 시뮬레이션 제안 목표값 및 입력 파라미터 (한눈에 보기)

> **중요 — 팀 최종 확정값이 아님:** 아래 수치들은 업로드한 ZIP의 **Gaussian/LSS 사전 계산과 Sentaurus Process `.cmd` 초안에 적용된 초기 제안 조건**입니다. 현재 팀이 확정한 것은 **평판 Si**, **주입 횟수 1·2·3·4회 비교**, **횟수별 총 Dose 동일**, **동일한 주입 조건에서 RTA Case A/B 비교**라는 *설계 원칙*입니다. 구체적인 수치는 강의자료·문헌, 단일 주입 TCAD 결과와 모델 검증 후 결정합니다.

### 1. 목표 도핑 프로파일

| 항목 | 제안값 | 의미 / 해석 |
|---|---|---|
| **목표 깊이 구간** | **0.05–0.45 µm** (50–450 nm) | Si 표면으로부터 이 범위에서 **Box-like** 농도를 형성 |
| **목표 구간 폭** | **0.40 µm** (400 nm) | 0.45 − 0.05 µm |
| 목표 구간 중심 깊이 | 0.25 µm (250 nm) | 구간의 기하학적 중심이며, **각 주입의 목표 `Rp`와는 다름** |
| **목표 Boron 농도** | **1×10¹⁷ cm⁻³** | 관심 구간에서 가능한 한 균일하게 유지하려는 도펀트 농도 |
| **총 주입 Dose** | **4×10¹² cm⁻²** | 1~4회 모두 동일한 총량을 사용하도록 한 **제안 수치** |
| 주입 횟수 | **1·2·3·4회** | **팀 확정 비교 범위**. 개별 에너지 및 Dose 배분은 회차별로 달라질 수 있음 |

목표 분포는 관심 구간에서 `C_B(x) ≈ 1×10¹⁷ cm⁻³`가 되도록 하는 것입니다. 이상적인 직사각형 분포라면 `Dose = 목표 농도 × 구간 폭 = (1×10¹⁷ cm⁻³) × (4×10⁻⁵ cm) = 4×10¹² cm⁻²`입니다. **실제 주입 분포는 구간 밖으로도 확장되므로 총 Dose가 이 값이라고 목표 농도를 정확히 달성하는 것은 아닙니다.** 평탄도와 구간 평균 농도 오차를 모두 비교합니다.

### 2. 기판·이온주입·격자·RTA 입력 조건 (ZIP 초안)

| 구분 | 파라미터 | 현재 제안 / 입력값 | 비고 |
|---|---|---|---|
| 기판 | 재료·전도형 | **평판 n형 Si** | 소자 구조가 아닌 1D 공정 프로파일 모델 |
| 기판 | **결정방향 (Wafer orientation)** | **Si (100)** | `.cmd`에서 `wafer.orient=100` 사용 — 설치 버전의 문법 확인 필요 |
| 초기 도핑 | Dopant / Concentration | **Phosphorus (P), 1×10¹⁵ cm⁻³** | 초기 기판 농도 |
| 주입 | **주입 이온종** | **Boron (B, ¹¹B⁺ 제안)** | `.cmd`에는 `implant Boron`으로 작성 |
| 주입 | 입사각 Tilt / Rotation | **7° / 22°** | 모든 비교에서 동일하게 유지하는 제안값 |
| 주입 | 에너지 | 아래 1~4회 후보표 참조 | LSS 예측을 바탕으로 선정한 시작값 |
| 주입 | 주입 순서 | **높은 에너지 → 낮은 에너지** | 현재 `.cmd`의 순서; RTA A/B에서 동일하게 유지 |
| 격자 | 기본 표면 / 0.6 µm / 2.0 µm 부근 설정 | **1 nm / 2 nm / 20 nm** | **격자 지정점의 간격 설정값**이지 전체 영역의 균일한 간격이 아님 |
| 격자 수렴성 | S0 표면 Grid 후보 | **0.5 / 1 / 2 / 5 nm** | S0는 에너지 Sweep이 아니라 격자 검증; 이때 80 keV, 1×10¹² cm⁻² 고정 |
| 열처리 | 기본 RTA 온도 / 시간 | **1050°C / 회당 10초** | 연구용 제안값. 승온/냉각 상세 조건 및 물리 모델은 미확정 |
| 열처리 방식 | **Case A / Case B** | **매회 RTA / 모든 주입 후 최종 RTA 1회** | **팀 확정 비교 방식**. 다른 조건은 동일하게 맞춤 |

### 3. 주입 횟수별 초기 에너지·Dose 배분 후보

아래는 [`analysis/designs_lss.json`](analysis/designs_lss.json)의 **LSS 근사 기반 예측 설계**를 읽기 쉽게 반올림한 값이며, **TCAD 실행 결과 또는 팀 최종 파라미터가 아닙니다.**

| 횟수 | 에너지 후보 (keV, 낮은 순서) | 에너지별 개별 Dose (×10¹² cm⁻², 같은 순서) | 총 Dose (cm⁻²) |
|---|---|---|---|
| 1회 | 110 | 4.000 | 4×10¹² |
| 2회 | 35 / 115 | 약 1.396 / 2.604 | 4×10¹² |
| 3회 | 20 / 55 / 130 | 약 0.643 / 1.310 / 2.047 | 4×10¹² |
| 4회 | 20 / 50 / 100 / 170 | 약 0.462 / 0.850 / 1.099 / 1.589 | 4×10¹² |

- 표는 보기 편하게 에너지를 **낮은 순서**로 나열했지만, 현재 TCAD 입력 코드에서는 **높은 에너지부터 주입**합니다. 정확한 Dose는 JSON과 `.cmd` 파일을 확인하세요.
- 에너지별 `Rp`는 서로 다릅니다. **0.25 µm는 목표 구간의 중심이지 모든 주입의 공통 주입 깊이가 아닙니다.**
- 170 keV의 LSS `Rp`/`ΔRp` 참고값은 출처 검증이 남아 있으며, 현재 `.cmd` 코드의 모델 설정·명령 문법도 학교 Sentaurus 버전에서 확인해야 합니다.
- 이 조건들의 선정 이유 및 근사 한계는 [사전 자료조사 2장](box_profile_사전자료조사.md#2-파라미터-재설정--값마다-근거)을 참고하세요.

## 팀 프로젝트에서 확정한 내용 vs. 이번 ZIP의 제안 조건

**팀 확정:** 평판 Si, 1·2·3·4회 주입 비교, **횟수별 총 Dose 동일**, 시뮬레이션 3은 동일 주입 조건의 **Case A(매회 RTA) vs B(마지막 한 번 RTA)** 비교. Retrograde well은 배경 사례일 뿐 직접 구현 대상이 아닙니다.

**이번 ZIP의 시작 조건(팀 확정 아님):** 이 README 상단의 [시뮬레이션 제안 목표값 및 입력 파라미터](#시뮬레이션-제안-목표값-및-입력-파라미터-한눈에-보기)에서 기판 결정방향·이온종·목표 깊이/폭·목표 농도·Dose·주입각·RTA 및 에너지별 초기 후보를 표로 정리했습니다.

에너지 조합 및 평탄도 지표는 **LSS 근사·탐색 범위 안에서 구한 초기 후보**입니다. 실행 전 공식 매뉴얼·강의자료와 TCAD 단일 주입 결과로 재검토해야 합니다.

## 완료 여부 / 해석상 주의

| 항목 | 상태 |
|---|---|
| 참고문헌 기반 검토·설계 문서 | ZIP에 작성되어 있음(출처별 타당성 재검토 필요) |
| Python Gaussian/LSS 계산·예측 그래프 | ZIP에 산출물 포함 |
| TCAD `.cmd` 46개 | **입력 파일 작성됨**, 환경 호환성 미검증 |
| Sentaurus 실행 로그·`.plx`·`.tdr` | **원본 ZIP에 없음** |
| 실제 TCAD 프로파일·결과 분석 | **실행 확인 전, 미확보** |

`AdvancedCalibration`, `wafer.orient`, `pdbSet`, `SetPlxList`, `WritePlx` 등을 학교에서 쓰는 Sentaurus 버전과 대조해야 합니다. 코드의 `TEDon`/`TEDoff`는 **서로 다른 확산 모델명에 붙인 비교용 이름**이므로 그 결과 차이를 TED 효과만으로 해석하면 안 됩니다.
